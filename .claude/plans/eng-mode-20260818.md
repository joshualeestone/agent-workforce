- engine/engmode.js mirrors limits.js minus tiers: { on: false } in
  engmode.json, fail-toward-OFF (the default IS the safe direction
  here: an unreadable preference must not reveal a surface the person
  never chose to show).

  treatment and the not-built line retire); same guarded handler shape
  as the limit card.

  an agent, and after a settings save; no per-5s polling of a
  preference (a mid-session change lands on the next navigation).
- The drive flips: the project viewport HIDDEN is the new default
  truth, with an engmode-on state proving the reveal.
