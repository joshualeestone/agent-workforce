# The one-line install: curl -fsSL chaoskosmos.com/setup | sh

**Dates:** 2026-08-12 (installer + tmux bundling) and 2026-08-13 (the app
bundle, the kosmos command, hardening)
**Requested by:** Josh; the install line is deficit #1 on the launch backlog
(the marketing page publishes the line; the page is the spec)
**Repo:** joshualeestone/agent-workforce, branch `install`

## The shape of the install

One pasted line, for a person who may never have opened Terminal. It must:
narrate every step before doing it; speak failures as sentences with a next
step; need no sudo; write nothing outside $HOME; be safe to run twice; be
genuinely reversible with --uninstall. It runs under macOS `sh` (bash 3.2 in
POSIX mode) piped from stdin, on a clean Mac: no Homebrew, no Xcode CLT (so
nothing in the user path may invoke python3), no node, no tmux. Apple
silicon, macOS 13.5+ (the floor the shipped Node runtime is built for; the
installer gates it in a sentence and the builders gate every artifact
against the same number).

## The pieces

1. `install/setup.sh`: the installer the page distributes. Fetches two
   tarballs from chaoskosmos.com/dist, each checksum-verified against a
   published .sha256 before extraction, staged fresh and swapped into place
   (never merged over an old tree). Creates a locally-built Kosmos.app icon
   (never downloaded, so never quarantined) and a ~/.local/bin/kosmos
   symlink. Uninstall stops the board, removes the symlink/home/app, and
   stops + removes the agents' launchd jobs while leaving the agents' files.
2. `install/kosmos` (ships in the bundle as bin/kosmos): start / stop /
   status / open / version. Resolves its home through the symlink by hand,
   puts the bundled tmux first on PATH, pins TERMINFO_DIRS, identifies the
   board by its page (not a bare 200) so a port squatter is named instead of
   opened, waits for the board to answer rather than for a pid.
3. `tools/build-tmux-bundle.sh`: relocatable ~2MB tmux (binary + three
   dylibs, load paths rewritten, ad-hoc signed, verified), packed with its
   .sha256.
4. `tools/build-kosmos-bundle.sh`: the app + a checksum-verified pinned
   Node runtime from nodejs.org + bin/kosmos, smoke-tested by booting the
   STAGED tree and requesting its page, packed with its .sha256.

## Provider rule

The installer never names a provider (decided with Josh, 2026-08-12).
Choosing a provider inside the app is what installs it.

## Verify

Sandboxed full-lifecycle battery on this machine (which runs a real board
on 4317, untouched): every write root overridden, local tarballs served
over HTTP, piped into `sh` exactly as the page distributes it. Install,
health, symlinked command, checksum tamper refusal, stale-file swap
semantics, stop, idempotent rerun, squatter sentence, uninstall (symlink
gone, launchd jobs removed, user data intact). Plus the repo's 529-test
suite and sh/bash parse checks.

## Known remaining work (named, not hidden)

- The tmux bundle is currently sourced from the build machine's Homebrew
  tmux, which stamps that machine's macOS as its minimum (minos 26.0 here,
  measured). The build now REFUSES to pack such a bundle for release
  (KOSMOS_ALLOW_MINOS=1 permits local test builds only). Before launch the
  tmux + dylibs must be built against the 13.5 floor (source build with
  MACOSX_DEPLOYMENT_TARGET, or bottles targeting the floor).
- Checksum sidecars share the tarballs' origin: they catch corruption, not
  a hostile origin. Artifact signing with an out-of-band key is on the
  launch security list (Josh's hard-testing directive).
- App icon artwork (Kosmos.icns) does not exist yet; the plumbing ships it
  from app/assets/ when it lands (the builder stages assets/ when present).
- The repo has no LICENSE file at its root; the page claims "Free, Open
  Source App", so the licence choice is Josh's call before the repo goes
  public.
- tools/third-party-notices.txt's libevent section should be replaced with
  the verbatim upstream LICENSE of the exact libevent version shipped
  (upstream carries additional copyright holders) before the repo goes
  public.
