# app-icon: the gold K lands in Applications

Date: 2026-08-13. Branch: app-icon.

## What and why

The clean-machine re-run tonight confirmed everything works and showed
the one cosmetic gap: the generic placeholder icon in Applications,
because no Kosmos.icns had ever shipped. Josh supplied the 1024px gold-K
master (his artwork, in-house, no third-party notice needed). This
branch ships the icon.

## The change

- assets/Kosmos-1024.png: Josh's full-bleed master, committed verbatim.
- assets/Kosmos-1024-shaped.png: the same artwork on the macOS icon grid
  (824px rounded rect, transparent margin, soft shadow), because macOS
  does not round icons itself and a full-bleed square reads foreign in
  the Dock. Flagged to Josh with a rendering; shaped is the shipping
  default, full-bleed is a one-file swap if he prefers it.
- assets/Kosmos.icns: the full icon set generated from the shaped master
  with sips + iconutil (16/32/128/256/512 plus @2x densities). Only the
  .icns ships in the bundle (explicit-list copy); the masters stay
  repo-only.
- README's install paragraph updated: the artwork-pending caveat is done.
- install/setup.sh: the bundle plist now declares LSArchitecturePriority
  arm64 + LSRequiresNativeExecution, because the first real desktop
  click produced "To open Kosmos, you need to install Rosetta": the
  executable is a shell script, LaunchServices cannot read an arch from
  it, and on Apple silicon it then demands Rosetta for a fully native
  app. The harness pins the plist keys (the mechanism); the prompt's
  absence (the symptom) can only be proven by a real Finder double-click
  on the mini after the update, recorded as the follow-up check.

Existing plumbing verified in code (not assumed): make_app copies
app/assets/Kosmos.icns into the .app when present, Info.plist names
CFBundleIconFile Kosmos, and lsregister -f refreshes a REPLACED bundle
on update. Caveat recorded: a Dock that already pins Kosmos may keep its
cached tile until the Dock restarts.

## Validation

yarn test (the full suite); a rebuilt kosmos bundle whose staged tree
contains app/assets/Kosmos.icns; yarn test:install against the rebuilt
bundle including the icon actually landing inside the created .app.
