# app-icon: the gold K lands in Applications

Date: 2026-08-13. Branch: app-icon.

## What and why

The clean-machine re-run tonight confirmed everything works and showed
the one cosmetic gap: the generic placeholder icon in Applications,
because no Kosmos.icns had ever shipped. Josh supplied the 1024px gold-K
master (his artwork, in-house, no third-party notice needed). This
branch ships the icon.

## The change

- assets/Kosmos-1024.png: Josh's master, committed verbatim.
- assets/Kosmos.icns: the full macOS icon set generated from it with
  sips + iconutil (16/32/128/256/512 plus @2x densities).
- README's install paragraph updated: the artwork-pending caveat is done.

No code changes: build-kosmos-bundle.sh already packs assets/ into the
bundle at app/assets/, make_app already copies app/assets/Kosmos.icns
into the .app when present, Info.plist already names CFBundleIconFile
Kosmos, and lsregister -f already refreshes a REPLACED bundle's icon on
update, so an in-place update on the mini picks it up.

## Validation

yarn test (the full suite); a rebuilt kosmos bundle whose staged tree
contains app/assets/Kosmos.icns; yarn test:install against the rebuilt
bundle including the icon actually landing inside the created .app.
